This document lists the third-party components used by the VM and its
commands, and the licenses under which they are distributed. Full license
texts are included in [`third_party/`](third_party/).

## The `mrbvm` library

The `mrbvm` package imports the bytecode contract from `go-mrbc`:

| Component | License | Copyright |
| --- | --- | --- |
| [go-mrbc](https://github.com/onohiroki/go-mrbc) `bytecode` | MIT | Copyright (c) 2026 go-mrbc contributors |

The VM library itself does not link go-ruby-prism, Prism, or wazero.

## The `gomruby` command

`gomruby` can compile `.rb` files on the fly, so its binary also links the
compiler stack:

| Component | Version | License | Copyright | License text |
| --- | --- | --- | --- | --- |
| [go-mrbc](https://github.com/onohiroki/go-mrbc) | local/tagged release | MIT | Copyright (c) 2026 go-mrbc contributors | https://github.com/onohiroki/go-mrbc/blob/main/LICENSE |
| [go-ruby-prism](https://github.com/danielgatis/go-ruby-prism) | v1.3.0 | MIT | Copyright (c) 2024 Daniel Gatis | [LICENSE.txt](third_party/go-ruby-prism/LICENSE.txt) |
| [Prism](https://github.com/ruby/prism) (embedded as `prism.wasm`) | as bundled by go-ruby-prism v1.3.0 | MIT | Copyright 2022-present, Ruby developers | [LICENSE.md](third_party/prism/LICENSE.md) |
| [wazero](https://github.com/tetratelabs/wazero) | v1.9.0 | Apache-2.0 | Copyright 2020-2023 wazero authors | [LICENSE](third_party/wazero/LICENSE), [NOTICE](third_party/wazero/NOTICE) |
| Go standard library and runtime | Go toolchain | BSD-style | The Go Authors | https://go.dev/LICENSE |

A `gomruby` build that only runs precompiled `.mrb` files still links the same
runtime code, so the notices apply to the binary distribution.

## Generated bytecode

`.mrb` files generated from user Ruby programs are not claimed by this
project's MIT License. Their licensing is determined by the input program and
the user's own distribution terms.

## Redistributing

- **Source distribution:** keep `go.mod`, `go.sum`, `LICENSE`, `NOTICE`,
  `THIRD_PARTY_LICENSES.md`, and `third_party/`.
- **Binary distribution:** include `LICENSE`, `NOTICE`,
  `THIRD_PARTY_LICENSES.md`, and the license texts under `third_party/`
  (especially the Apache-2.0 `LICENSE` and `NOTICE` for wazero).
- **Vendored builds:** if you commit `vendor/`, keep the license files that
  Go copies into the vendor tree, and keep this document with the
  distribution.
- **`.mrb` runtime only:** a VM that only consumes `go-mrbc/bytecode` does
  not need the parser dependencies, but the distributed binary still needs
  the notices for the code it links.
