# go-mrbvm v0.1.1

This is a hardening release on top of v0.1.0.

## Requirements

- `go-mrbc` v0.1.1
- mruby 4.0.0 / RITE 04.00

## Highlights

- Serialized Enumerator producer/consumer handoff and Fiber shutdown; the full
  suite now passes under `go test -race`.
- Added `State.Close`, which stops the scheduler, waits for internal
  Fiber/Enumerator goroutines, and closes tracked files.
- Recovered internal panics and added a `FuzzRun` / `FuzzDecodeBytecode` smoke
  gate.
- Enforced capability checks for `eval`, `load`, and `require`. Standard I/O
  remains host-controlled.
- Added `MaxFibers`, `MaxEnumerators`, and a coarse `MaxMemory` budget;
  instruction/time/output budgets reset per `Run` / `Execute`.
- Shared the output budget across stdout and stderr and tightened array,
  string, hash, regexp-substitution, and format-size checks.
- Added deterministic `Time.now` / `object_id` via `Deterministic` and
  `Clock`.
- Added seeded random differential runs against C mruby, macOS/Windows unit CI,
  nightly lifecycle soak tests, and benchmark baselines.
- Added `go-mrbc` v0.1.1 bytecode validation for frame sizes, jumps, and catch
  handlers.

## Known limitations

- `MaxMemory` is coarse heap-growth accounting checked at instruction
  boundaries; precise per-object accounting and `ObjectSpace` are not yet
  implemented.
- Seeded `rand` is not implemented.
- The official manifests are still allowlists; see
  [`docs/official-tests.md`](../official-tests.md).
